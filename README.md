# Bread Bot

A bread recipe calculator. Pick a bread type (sourdough, bagel,
sourdough bagel, rye loaf, sandwich loaf), a hydration level appropriate
to that bread, how many loaves you want, and how big each loaf should be.

Bread Bot tells you how many grams of each ingredient to weigh, how long
to ferment and proof, and what temperature and time to bake at.

Everything runs client-side. The numbers follow standard baker's
percentages (everything scaled off total flour), and each loaf size is a
dough weight before baking loss.
